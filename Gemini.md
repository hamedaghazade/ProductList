# Project Rules

You are working on a Telegram Bot and Telegram Mini App.

Rules:

1. Do not rewrite working code unnecessarily.
2. Before modifying files, inspect existing project structure.
3. Preserve existing functionality.
4. Do not delete files unless explicitly requested.
5. Explain important architectural changes.
6. Keep frontend and backend responsibilities separate.
7. Validate user input.
8. Never expose secrets, API keys, tokens, or passwords.
9. Use environment variables for secrets.
10. Write maintainable production-ready code.
11. When fixing bugs, identify root cause before changing code.
12. After changes, check for related errors.
13. Do not install dependencies unless necessary.
14. Prefer stable and well-maintained packages.
15. Keep code modular.
